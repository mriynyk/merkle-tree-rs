# mriynyk-merkle-cli

[![crates.io](https://img.shields.io/crates/v/mriynyk-merkle-cli.svg)](https://crates.io/crates/mriynyk-merkle-cli)

Command-line interface for [`mriynyk-merkle`](https://crates.io/crates/mriynyk-merkle) —
Merkle tree utilities for the EVM. Installs a `merkle` binary.

> ⚠️ **Early placeholder release.** No commands are available yet.

## Installation

```sh
cargo install mriynyk-merkle-cli
```

This installs the `merkle` binary:

```sh
merkle
```
